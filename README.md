# foolstrap
Fool's trap is a Windows x64 program that sends back a fake banner as a reponse of a scan or request.

Just run foolstrap.exe then a TCP port will be open on your Windows machine and a fake answer will be sent back.

This tool can be used for:
- Cyberdeception
- testing connectivity

It was tested on Windows 11 Home/Pro against telnet, nc and nmap.

# Installation

Installation is easy: just download the executable.

# Usage

Run the program.

``` PowerShell
C:\>foolstrap.exe
Server running. Waiting for connection...
```
